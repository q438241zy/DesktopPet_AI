# 五项互动图稿

覆盖8位角色×Q版/3D真人×原装/泳装/婚纱/运动服，共64套外观。每套包含20种关键姿势，批准的DeepSeek原装沿用24姿势图集。

`selected-expansion.json` 记录62套扩展的选用来源，另两套为已批准DeepSeek原装。`installation.json` 记录安装结果和原始PNG摘要。各次提示词、参考图和原始生成文件保留在本目录，不把未选用稿加入运行包。

比例沿用本角色本服装的原生立绘；3D真人使用完整成年全身体型，不能用总高度缩放掩盖腿部比例差异。运动服为短袖及膝上短裤。图集使用固定参考高度、逐姿势脚底和手心/礼盒/书本坐标；测量工具只写元数据，不修改图像像素。

击掌等待用户触碰后靠近接掌，猜拳双方摇拳后同时亮手，礼物接到手中后打开，书页配合逐句阅读，合照保存完整人物。连续位移及阶段时序由代码编排，关键姿势切换仍属于图集动画。

最终验证与运行包记录见 `docs/verification-preview25.md`。
