## 本轮交互

| 项目 | 网页中的行为 |
| --- | --- |
| 会员测试开放 | 五档无权限拦截，聊天直接在角色上方输入，默认本地多轮回复；每轮先思考至少 1 秒 |
| 一级菜单 | 聊天直接在第一层；原“动作”入口命名为“互动” |
| 右键 | 只展开/收起圆盘；不重置动作、计时、移动位置、步态相位或躲藏状态；进入子菜单也继续播放 |
| 躲藏 | 一个入口，每次等概率选择左/右，走到边缘后藏好；左键找到并走回来，右键只开菜单 |
| 梳头（新照顾） | 梳子沿左右两侧头发分段往下梳，最后收起 |
| 擦脸（新照顾） | 柔软毛巾依次轻擦两边脸颊 |
| 陪伴呼吸（新照顾） | 光圈按 3 秒吸气、3 秒呼气扩缩；角色维持固定比例 |
| 吹泡泡（新玩耍） | 泡泡从嘴边飘起，可点击戳破并计数 |
| 接星星（新玩耍） | 点星星后沿弧线飞到当前外观的掌心，到达后计数 |
| 捉蝴蝶（新玩耍） | 点击空处引导蝴蝶，角色走过去，停下后蝴蝶落到掌心 |

六项新互动是复用现有画稿的道具、时序与交互编排样例，尚未新增专用角色姿势。不把角色全身摆动、缩放或图片叠影称为新画稿。六套外观各自标定头发、脸、嘴、掌心的坐标；梳头/擦脸等选用无额外原生道具的安静姿势，避免叠加摸头手掌等重复特效。

渲染保持原生 560×680 帧的完整画布及统一脚底基准，不按单帧轮廓缩放。切换服装仅从该外观选帧，未加载时不回退到别的风格。步态相位按实际位移推进，左右行走只镜像现有的朝右步态。
