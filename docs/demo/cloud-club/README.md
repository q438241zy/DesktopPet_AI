## 本轮交互

| 项目 | 网页中的行为 |
| --- | --- |
| 会员测试开放 | 五档无权限拦截，聊天直接在角色上方输入，默认本地多轮回复；每轮先思考至少 1 秒 |
| 一级菜单 | 聊天直接在第一层；原“动作”入口命名为“互动” |
| 右键 | 只展开/收起圆盘；不重置动作、计时、移动位置、步态相位或躲藏状态；进入子菜单也继续播放 |
| 躲藏 | 一个入口，每次等概率选择左/右，走到边缘后藏好；左键找到并走回来，右键只开菜单 |
| 梳头（新照顾） | 梳子沿左右两侧头发分段往下梳，最后收起 |
| 擦脸（新照顾） | 柔软毛巾依次轻擦两边脸颊 |
| 伸懒腰（替换陪伴呼吸） | 专用抬手、向上伸展、放松收手的姿势，连续过渡 |
| 吹泡泡（修订） | 举起棒子、送嘴、吹气、看泡泡、收手；只有吹气阶段产生泡泡，点击可戳破 |
| 数星星（替换接星星） | 按“改成数”理解：抬头并伸手指星星，自动依次计数 1→5，星星逐个高亮；点击星星重新数 |
| 捉蝴蝶（新玩耍） | 点击空处引导蝴蝶，角色走过去，停下后蝴蝶落到掌心 |

伸懒腰、吹泡泡、数星星使用内置 image_gen 新绘的专用图集，每项/每套外观 8 个关键姿势。连续位移由双向图像对应关系驱动，颜色始终来自原图，避免整个人物的缩放和长时间淡入淡出。相邻帧的大幅手势切换在中点只选一张颜色图，避免半透明双手。每个姿势都有连通部件归属元数据，采样时隔离其他行的鞋尖等零碎部分。原始 PNG 不做重绘、裁切或像素修改；Python 只读取图片并输出 JSON/JS 元数据。

梳头、擦脸、捉蝴蝶仍为上一轮现有画稿的交互编排。六套外观保持头发、脸、嘴、掌心坐标；专用吹泡泡画稿已包含泡泡棒与瓶子，程序不再重复画一根棒子。

原生帧继续保持完整 560×680 画布；新动作按该动作首帧的中立姿势校准比例，随后所有 8 帧使用同一个比例，不能按举高手臂后的外轮廓重新缩放。切换服装只选该外观图集。步态相位按实际位移推进，左右行走只镜像现有的朝右步态。
