## 打开与审阅

部署后打开 `Release/win-x64/Demo/CompanionV01/index.html`。桌面原有 `DeepSeek-動作Demo.lnk` 仍指向 CloudClub，顶部新增本页入口。

- 宠物行事历：左侧入口，或 URL 加 `#agenda`。八位共享日程、记录负责提醒的角色；周/月查看、确认卡、修改/删除、提前提醒和单次/每天/工作日/每周重复。点原角色卡下方「聊聊天 / 记日程」使用原聊天输入。三个固定演示不调用 API；真实输入复用设定中的八家接口。
- 提醒：HTML 页面可见时按本机时刻触发，返回或重开时检查遗漏，已完成／10 分钟后结果持久化；预览不会改变真实日程。页面关闭时没有后台服务。原生 v1.2 使用独立调度，程序运行且宠物隐藏时也可提醒；原生与 Demo 存档分开。

- 我的伙伴：八位角色卡下方恢复原控制面板的卡片，原图等比显示，包含名称、风格、相处记录与原装/运动服/泳装/婚纱切换。不同角色、不同风格分别记住服装。右键角色卡片进入档案；“伙伴档案”按钮与 Shift+F10 提供等效入口。
- 待机姿态：卡片下方选择“自动 · 30秒 / 站立 / 坐下”。默认交错站坐，自动每 30 秒轮换；每位角色分别记住模式，Q版与3D真人共用模式。暂停陪伴、减少动态、页面隐藏或打开对话框时不轮换，当前互动、菜单、聊天草稿和待确认日程也不会被待机替换。恢复后从完整 30 秒重新计时，固定站立/坐下不轮换。自动换姿势不算用户操作，不推迟一分钟躲藏。使用本套服装的现有原图帧，站坐共用预留显示空间和脚底基线，不生成新图或局部拉伸。
- 档案：我们的默契、风格预览、说明三个分页。“说明”介绍人物个性、四项喜好和相处方式，不展示模型指令；Q版与3D真人共用说明和角色记录。每个角色分别记录 −100 至 +100 的关系值和可见页面上的陪伴时间。
- 聊天与合照：档案“说明”页的“和她聊聊”进入独立预览，或点击左下角版本 → “聊天与合照预览”。输入框仍在角色上方，主页原图卡不再承担互动舞台功能。
- 躲藏：在独立预览中默认闲置一分钟后触发，或点击“躲藏”；先走向随机边缘，再留在边缘等左键找到。右键只切换菜单，不返回。正在输入草稿、打开分页或对话框时不自动躲藏，主页原图卡也不会自行走开。
- 设定：工作模式默认关闭，开启开关后才显示设置并按已保存间隔计时；间隔 1–180 分钟，默认 10 分钟，修改后点击“保存间隔”。无须填写提醒内容，八个角色各六种预设话语轮换；模型已设置且本次会话有 Key 时自动生成简短提醒，等待或失败期间仍使用预设话语，并标明实际来源。关闭开关同时停止计时、撤下提醒、取消未返回请求；试提醒不改变周期。重开页面时仅恢复开关与间隔，从完整新周期开始，不补发关页期间提醒。每轮使用当前人物笑脸；不会打断躲藏或聊天。暂停陪伴会暂停倒计时。浏览器关闭不提供后台服务。
- 合照：从当前伙伴卡的“一起合照”或互动菜单进入。当前伙伴固定入镜，可多选其他伙伴或全选，共 2–8 位，沿用当前风格和每位所选服装。输入最多 60 字，选择暖云/浅玉/奶油相框；2 人导出 1200×1400、3–4 人 1800×1350、5–8 人分两排导出 1800×1760 PNG。整组合用同一尺度，按可见发丝、裙摆和尾巴预留位置，防止裁切和相互遮挡。修改选择、文字或相框后须重新生成才可保存，未完成的旧请求不会覆盖新内容。保存时优先调用浏览器保存选择器并定位桌面；不支持此能力的浏览器只能下载，页面会说明实际结果。取消保存不会产生成功提示。
- 陪伴日常：月历/周历切换，直接点击今天打卡，每日一次；今天用玫瑰色，已签日期保留数字并标记。支持翻看往月、返回今天和跨日自动更新；连续/累计天数及球区、食物区、故事区保留。补签卡默认 0 张，不自动发放或购买；有卡时点击过去的漏签日期，经确认消耗 1 张，取消不扣卡，补签修复日期/连续记录，不虚构陪伴时间或补发好感。旧存档自动补齐计数。“拆份礼物”入口及抽取逻辑已移除，已有收藏计数保留；20 种物品清单仍用于展示，非食物日常物品保存在“其他小物”。三篇 7–8 句原创故事读到最后并确认后收藏。本次只移除这页入口，未删除已批准的原生拆礼物互动。
- 会员中心：登录、注册分页；本机 Demo 账号，随机盐与 PBKDF2 摘要，密码不存明文，刷新后重新登录。未提供云端账号服务。
- 点击左下角版本号可使用“模拟闲置一分钟”“推进一个提醒周期”和当前角色关系值滑杆。只改变测试存档，不冒充真实陪伴时长。

## 已确认的本轮规则

八位角色的说明、喜好和口吻保存在 `personas.js`，同一份定义同时用于本机多轮对白和 API 提示词；询问喜好和自我介绍会按人物设定回答，换衣或切换画风不改变设定。这是桌面虚构人物设定，不是对应厂商或真实模型的个人偏好。每次回复至少思考一秒；慢接口持续等待到回复或 45 秒超时，错误不伪装成本机成功回复。切换角色、风格、接口或退出账号会取消旧请求。

好感暂按打卡 +3、有效聊天 +1、摸头 +1、共读 +2、礼物 +2、安静陪伴五分钟 +1 试行。正向每天上限 20，有交互冷却；十秒内连续摸头六次触发温和边界与 −2，最低 −100，最高 +100。漏签和关闭程序不扣分。服装门槛暂提议原装 0、运动服 20、泳装 50、婚纱 80，未达成显示笑脸小锁；**测试期所有风格仍开放**。这些数值属于本轮方案，未经用户拍板不得强制用于正式解锁。

原生 v0.4 接入后台提醒、双角色合照与默认桌面保存、存档迁移及新界面。角色工房、生成器附件和专用导入器已移除；用户以前导入的角色和存档不删除。

## 接口检查

Demo 支持 GPT/OpenAI、Claude、Gemini、Grok、DeepSeek、Qwen、GLM、Kimi 八家。Claude 使用 Messages，Gemini 使用 generateContent，其余使用各自官方 Chat Completions 格式。请求、鉴权、回包解析、端点和官方来源见 [八家接口核对](../../companion-api-providers.md)。界面可保存设置并测试连接，模型名由用户填写已开通的型号；示例仅作占位提示。API Key 只留在页面内存，切换服务或编辑地址清空输入，刷新后重新填写。模拟检查不能证明实际账号、额度、网络和浏览器跨域可用。

原生适配位于 `CompanionProviders.cs`，由 HttpClient 调用相同协议；人物设定从本 Demo 的 personas.js 导出为核心内嵌 JSON，避免说明与回答分叉。

- [OpenAI Chat Completions 官方参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)：`https://api.openai.com/v1/chat/completions`。
- [DeepSeek 官方入门](https://api-docs.deepseek.com/)：`https://api.deepseek.com/chat/completions`，也接受 `/v1` 基础地址。2026-10-07 页面示例模型为 `deepseek-flash`；用户可改成账号可用的其他模型。

自动检查截获请求并返回模拟回复，验证端点、消息角色、认证头、内容解析与思考时长；没有调用付费模型，也没有声称实际 API Key 已验证。浏览器直接访问用户填写的接口可能受 CORS 限制，错误有明确反馈；原生通过 HttpClient 请求，不受浏览器 CORS 限制；账号与实际网络连通性仍需真实配置验证。

## 构建与验证

```powershell
python tools/build-companion-demo.py
./tools/install-companion-demo.ps1
node tools/verify-companion-demo.cjs Release/win-x64/Demo/CompanionV01/index.html
node tools/verify-companion-boundaries.cjs
node tools/verify-companion-providers.cjs
node tools/verify-companion-calendar.cjs

```

`data.js` 和 `.generated/photos` 由现有角色清单、原始 PNG/WebP 与 `Version.props` 生成，不提交重复的图像编码。所有图片像素不变；透明边界测量只生成定位与固定缩放元数据。合照按需加载原图编码，解决 file 页面画布无法导出的问题。合照图片缓存最多 8 张，其余预览最多 48 张，退出或刷新释放。

验证脚本使用真正 Chromium file 页面、鼠标点击、键盘输入和 PNG 导出；计时长周期通过 Demo 时钟推进检查。v0.4 月/周历11组报告位于 `.artifacts/companion-v04-review`；回归脚本可通过 `COMPANION_REVIEW_DIRECTORY` 指定报告目录，检查前后核对日常 exe 和 state 文件哈希。补签测试的卡片仅注入隔离浏览器上下文，不修改用户存档。八家请求由测试路由截获并回包，不使用真实付费密钥。
