试三种手势

  1. 快速抓起：从底部提起后立即松手，会掉回任务栏。
  2. 主动摆放：往上拖后停半秒，或慢慢移动，松手会停在新位置。
  3. 半空接住：掉落时再次抓住，可重新调整并固定。

需要快速放到高处？按住 Shift 松手即可固定。

Demo 边界

这是离线浏览器原型，直接使用当前宠物渲染帧。任务栏只是模拟区域；实际 Windows 鼠标、任务栏遮挡和多屏幕规则要在原生程序中验证。

观察重点：从任务栏起手才有自然落下；从半空重新抓取、明确摆放和普通上移都不自动掉落。此页尚未改动正在运行的宠物。
