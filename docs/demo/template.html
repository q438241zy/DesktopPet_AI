這份 Demo 如何更新，以及它能驗證什麼

每次執行 pwsh -File tools/demo.ps1，都會重新讀取當前的角色包、動作清單和桌面渲染器，更新這份 HTML 及完整清單。圖像由同目錄的 frames 資料夾按動作載入，可離線開啟；移動時請保留完整 Demo 資料夾。

「專用逐幀／專用姿勢」表示本外觀有對應美術；「程序動作」使用骨骼或特效；「近似動作」及「缺少動作」屬於待補。待機、聆聽和手動放置本來就可以保持安靜姿勢。

网页中的拖曳、球反應選擇與本機對話是展示邏輯，不能代替 Windows 滑鼠、跨螢幕或真實 API 驗收。此頁不會連接 API，也不收集金鑰。僅真人版提供舞蹈。
