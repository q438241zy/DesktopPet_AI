## 换装长期规则

以后新增服装都先与原图比较，以原图为换衣编辑目标。身份、脸型、头部大小、头身比、肩腰胯及腿长协调必须保持；不能只对齐总高度。提供同姿势并排和叠图，检查膝盖、脚踝、脚底与接触点；动作图集还要逐帧查看。保存原图、参考图、提示词与生成来源，先 Demo，用户拍板后才接入及拓展。

本次使用内置 `image_gen`，不重采样原始 PNG，也不用代码改造身体。W1 记录在 `art/provenance.json`；Q版运动服的完整提示词、参考哈希和审阅状态在 `art/sports-provenance.json`。六姿势选用 `deepseek-chibi-sports-v1.png`，行走选用 `deepseek-chibi-sports-walk-v2.png`；行走 v1 遗漏头饰，v2 定向恢复头饰，v1 仅留作生成来源。生成约束不等于像素完全一致，最终比例和身份仍通过原图对照审阅。
