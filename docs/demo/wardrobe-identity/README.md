# DeepSeek 换装对照 W1

2026-10-07。仅供用户审阅，还没有批准扩展或替换原生角色。

用户指出 Q版泳装变矮、变胖，3D真人运动服改变了角色体型。本轮以现有原装画稿作为编辑目标，保持身份和体型，替换服饰；3D真人同时提供已接受的泳装与婚纱作为身份参考。提示词原文在 `art/provenance.json`。

## 审阅入口

- 运行页：`Release/win-x64/Demo/WardrobeIdentity/index.html?review=W1`。
- 常态 `CloudClub` 顶部已链接此页，沿用桌面同一个 Demo 快捷方式。
- Q版：六种基本姿势与十二帧行走，可暂停、逐帧、左右翻转、切换现行泳装。
- 3D真人：短袖上衣与膝上短裤单张样稿；可与原装、泳装、婚纱分别比较。未制作新的全动作图集。
- 并排和叠图使用同一源画布与等比例显示；没有局部拉伸、按每帧包围盒重新归一化或隐瞒形体差异。底部衣橱缩略图仅供识别服饰，坐姿/站姿已标明。

`image_gen` 生成的原始 PNG 保留在 `art`，没有重采样或用代码改造身体。三张换装图的透明通道在浏览器实际浅色/深色背景下核验；独立图片查看器可能显示透明像素背后的 RGB，不应把它当成实际背景。

## 部署与验证

```powershell
./tools/install-wardrobe-identity-demo.ps1
node tools/verify-wardrobe-identity.cjs
```

检查覆盖六姿势、十二个不同的行走帧、方向、播放与暂停、旧装对照、叠图透明度与键盘按住看参考、三个成年比例参考、390px 窄屏与 2x 清晰度、常态 Demo 跳转。浏览器没有联网依赖或缺图。记录与截图在 `.artifacts/wardrobe-identity-W1`。

Demo 部署前后，正式 exe 和用户存档哈希未变。随后 Preview27 的程序更新只修复既有鼠标行为，新服装仍留在 Demo 等待确认。
