# Preview 20 · 云朵会员

主页「我的伙伴」加入注册 / 登录入口，左侧增加会员中心。五档展示使用黑金、珠光白金、暖金、柔银、杏桃黄铜；锁住的聊天图标右上方有带腮红笑脸的矢量小锁。圆盘继续保持透明背景。

| 等级 | 姿态 | 聊天 |
|---|---|---|
| 黑金 | 全部开放 | 开放 |
| 白金 | 等用户通知，暂保留现有姿态 | 开放 |
| 黄金 | 等用户通知，暂保留现有姿态 | 开放 |
| 白银 | 等用户通知，暂保留现有姿态 | 锁定 |
| 黄铜 | 等用户通知，暂保留现有姿态 | 锁定 |

未登录不影响现有基础陪伴；聊天需要已登录且达到黄金。当前没有编造其他姿态的等级要求，也没有提供自行选择等级或购买升级的入口。

## 当前注册方式

当前没有账号服务器，先完成可用的本机注册、登录、退出：账号 4–24 位字母、数字、下划线或短横线；昵称 1–20 个字符；密码 15–128 个字符，需要确认密码。账号不区分大小写。注册成功默认黄铜，并登录本次进程；重启后需要重新登录。重复账号、两次密码不一致、密码错误和本地资料损坏都有明确提示。

账号资料单独保存为用户数据目录中的 `member-accounts.json`，不修改 `state.json`、角色、衣服、打卡、收藏或聊天地址配置。密码采用独立随机盐和 PBKDF2-HMAC-SHA256 600000 次派生，不保存明文密码。依据 [.NET PBKDF2 API](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.rfc2898derivebytes.pbkdf2?view=net-10.0) 与 [OWASP 密码存储指引](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。连续五次密码错误后暂停登录一分钟。损坏的会员文件不被注册流程覆盖。

退出会取消正在进行的回复、清除当前对话和本次 API 金钥。会员权限在圆盘、日常页、`OpenChat`、`RunInteraction` 与发送消息时都检查，不能只靠隐藏按钮阻挡。本机会员文件由本机用户管理，不能充当收费产品的可信授权源。

## 后续接入

`IAccountService` 已隔开账号来源与 UI。后续提供服务端地址和注册规则后，实现同一个接口，通过服务端授予等级；注册请求没有等级参数。不要把聊天模型 API 地址当成注册接口。

姿态等级统一配置在 `DesktopPet.Core/Membership.cs` 的 `Requirements`。目前只有 `chat → Gold`；黑金是最高档，因此所有合法等级要求都放开。后续新增姿态规则时，圆盘和日常页自动使用同一判断与小锁。账号权限与相伴天数的等级完全独立。

常态 Demo 提供明确标注的「会员预览」选择器，只模拟权益，不注册账号或保存密码。数据来自原生 `--export-membership <JSON文件>`。刷新 UI 时使用 `tools/refresh-demo-template.py <HTML> --membership-rules <JSON>`；复用既有原生动作帧，分别标明界面版本与动作帧版本。
