# 项目整合记录

本项目于 2026-09-27 按仓库所有者要求，将 UsageDashboard_AI 的 Windows 桌面壳和 Character_Generator 的出图 Skill 整合为独立桌面宠物。

## 决定

使用 .NET 10 / WPF 原生透明窗口，直接解码现有 WebP 图集。桌面互动不依赖浏览器页面、DS Go 服务或平台账号。图集与定时由宠物窗口持有；角色切换和新互动取消旧手势与待完成回调。本地数据按独立目录保存。

1.1 预览版按最新要求移除小埋及经典服装，保留八位指定 AI 的 Q 版角色，并加入 DeepSeek 的 3D 动画、写实成年风格静态 Demo。原存档选择小埋时自动回退到 DeepSeek，打卡和收藏不受影响。用户给出的婚纱动作原稿保持原文件，运行时复用已对齐的正式图集。

1.2 衣橱预览版在已确认的两种成年画风上扩展全部八位角色，为 3D 与真人版各提供原装、泳装和婚纱，共 48 张静态立绘。界面增加全角色三种画风的服饰对照，静态角色在互动期间保持所选服装；完整逐帧动作仍待制作。所有新素材和清单位于本项目，未改动 DS Go 的原稿或工程。

1.2.0-preview.2 将动作回退限制在当前服装内，补入八张 Q 版泳装及 48 张 3D / 真人服装行走图集。分类按钮同步切换同一伙伴的画风并保留衣服。缺少专用互动图时使用当前外观的姿势图，不再跳回原装或 Q版；新增的行走图均保存在本项目。

原生成器是一套 Skill，不是图片生成服务。因此保留其完整 Skill，同时提供提示词界面和静态成果导入。工坊不直接调用图片 API。1.2.0-preview.7 新增可选的文字聊天 API；未填写地址时使用本机预设对话。

1.2.0-preview.5 扩展 3D 与真人版全部 48 套外观的程序骨骼互动与动作特效；休息改为桌面可见的小憩。玩球有十种运动玩具，散步从二十种常见物品抽取并保存到收藏；原有礼物和打卡记录继续兼容。修复了散步标记被特效超时提前清除、走完无法获得奖励的问题。

1.2.0-preview.6 将 3D 与真人版的吃零食、早餐和接球换成实际逐帧画稿：48 张九姿势图集，共 432 个关键姿势。按可见身高与脚底对齐，按每帧手掌校准球的位置和接触范围；食物画在手中，不再用单张立绘弯曲代替进食。触摸、休息及真人舞蹈仍使用原程序动画。

1.2.0-preview.7 为全部 48 套 3D／真人外观新增十六姿势互动图。聊天增加文字窗口、本机多轮预设和可选 API；倾听、说话、发呆分别选帧。跳跃、坐姿蜷起、侧躺休息、搭积木与工作列提起改用绘制姿势。玩球按最新要求恢复为球碰到身体后弹开和未碰到两种反馈，合并重复推球入口。旧存档、角色、衣服、打卡及收藏保持兼容。

## 迁移与恢复

删除旧仓库之前先保留完整本地克隆和 `git bundle --all`，并验证 bundle 可恢复全部历史。备份位于用户桌面的 `DesktopPet_Migration_Backup`，独立于本仓库与 DS Go；它不上传到新项目。

旧仓库原始提交分别为 `a09cc84d5f9cd14232d65178a2c245e3529b53b6` 与 `b147334b04e2b280a5ab171a67918d3904dab378`。迁移检查时两个仓库均无 Issue、Release、Star 或 Fork；仓库元数据另存于本地备份目录。

新项目不沿用旧仓库的账号配置或凭据，也不覆盖 DS Go 正在进行的工作。
