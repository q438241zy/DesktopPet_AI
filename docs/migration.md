# 项目整合记录

本项目于 2026-09-27 按仓库所有者要求，将 UsageDashboard_AI 的 Windows 桌面壳和 Character_Generator 的出图 Skill 整合为独立桌面宠物。

## 决定

使用 .NET 10 / WPF 原生透明窗口，直接解码现有 WebP 图集。桌面互动不依赖浏览器页面、DS Go 服务或平台账号。图集与定时由宠物窗口持有；角色切换和新互动取消旧手势与待完成回调。本地数据按独立目录保存。

内置角色限定为小埋与八位指定 AI 角色。原小埋素材保留为经典服装；DS Go 版小埋提供完整动作。其他旧角色不复制到新项目。用户给出的婚纱动作原稿保持原文件，运行时复用已对齐的正式图集。

原生成器是一套 Skill，不是图片生成服务。因此保留其完整 Skill，同时提供提示词界面和静态成果导入，避免把本地文本生成误标为自动绘图。当前没有在线聊天或图片 API。

## 迁移与恢复

删除旧仓库之前先保留完整本地克隆和 `git bundle --all`，并验证 bundle 可恢复全部历史。备份位于用户桌面的 `DesktopPet_Migration_Backup`，独立于本仓库与 DS Go；它不上传到新项目。

旧仓库原始提交分别为 `a09cc84d5f9cd14232d65178a2c245e3529b53b6` 与 `b147334b04e2b280a5ab171a67918d3904dab378`。迁移检查时两个仓库均无 Issue、Release、Star 或 Fork；仓库元数据另存于本地备份目录。

新项目不沿用旧仓库的账号配置或凭据，也不覆盖 DS Go 正在进行的工作。
