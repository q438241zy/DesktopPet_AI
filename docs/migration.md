# 项目整合记录

本项目于 2026-09-27 按仓库所有者要求，将 UsageDashboard_AI 的 Windows 桌面壳和 Character_Generator 的出图 Skill 整合为独立桌面宠物。

## 决定

使用 .NET 10 / WPF 原生透明窗口，直接解码现有 WebP 图集。桌面互动不依赖浏览器页面、DS Go 服务或平台账号。图集与定时由宠物窗口持有；角色切换和新互动取消旧手势与待完成回调。本地数据按独立目录保存。

1.1 预览版按最新要求移除小埋及经典服装，保留八位指定 AI 的 Q 版角色，并加入 DeepSeek 的 3D 动画、写实成年风格静态 Demo。原存档选择小埋时自动回退到 DeepSeek，打卡和收藏不受影响。用户给出的婚纱动作原稿保持原文件，运行时复用已对齐的正式图集。

1.2 衣橱预览版在已确认的两种成年画风上扩展全部八位角色，为 3D 与真人版各提供原装、泳装和婚纱，共 48 张静态立绘。界面增加全角色三种画风的服饰对照，静态角色在互动期间保持所选服装；完整逐帧动作仍待制作。所有新素材和清单位于本项目，未改动 DS Go 的原稿或工程。

原生成器是一套 Skill，不是图片生成服务。因此保留其完整 Skill，同时提供提示词界面和静态成果导入，避免把本地文本生成误标为自动绘图。当前没有在线聊天或图片 API。
