# 宠物行事历 · HTML 方案

状态：v1.1 HTML Demo，等待使用者审阅。沿用现有聊天、八位伙伴、两种画风和 API 设定；不接入原生程序、不制作安装包。

## 使用流程

1. 从「我的伙伴」点「聊聊天 / 记日程」，输入：**明天下午三点项目会议，提前十分钟提醒我。** 输入仍在宠物头顶。
2. 宠物至少思考一秒。已配置的 AI 接口判断普通聊天或记事，并将相对时间整理成明确日期；「明天提醒我买牛奶」缺少时间，就先追问。
3. 聊天画面下方出现日程卡：事情、日期时间、提前分钟、重复规则、负责提醒的伙伴。可直接修改；点「收进行事历」后才保存。错误、取消、过期时间或无效 AI 回包不会创建日程。
4. 左侧新增「宠物行事历」。上方显示下一件事，中间周/月切换，下方查看当天或全部待提醒／已完成记录。已保存日程可以修改，删除时确认。打卡继续留在「陪伴日常」。
5. 到点显示负责记事的宠物笑脸、事件和时间。选择「已完成」或「10 分钟后」。有多件事时逐条提醒；重复提醒在处理后推进到下一次。

界面沿用暖云朵与浅玉绿，使用现有笑脸图稿，不重新生成角色。八位宠物共用一本行事历，事件分别记住交给哪位宠物；切换画风和服装不改变日程。

## 第一版规则

| 项目 | HTML Demo 约定 |
| --- | --- |
| 输入 | 任意自然语言记事需要真实 API；未接入时普通聊天照常，记事入口引导设置 |
| 体验 | 三个明确标记的固定演示：会议、工作日收尾、缺少时间的追问；演示记录带标签 |
| 时间 | 本机时区，精度为分钟，确认卡显示绝对日期；不猜测模糊时间 |
| 提前提醒 | 0–10080 分钟；事件及提醒时间必须都在未来 |
| 重复 | 单次、每天、工作日、每周；日历先显示下一次发生时间 |
| 修改 | 第一版通过日程卡修改或删除；不让 AI 直接改动已保存记录 |
| 重复加入 | 相同标题与时间的活跃日程只保留一条，跨宠物也检查 |
| 延后 | 延后当前提醒 10 分钟，保留原事件时间 |
| 完成 | 单次进入已完成；重复事件按原来的钟点推进，跳过已错过的重复次数，不连发积压提醒 |
| 预览 | 「预览提醒」只看笑脸和话语，不提前完成事件，也不改变实际时间 |
| 断线 | 确认时保存事件和 AI 提醒话语；到点不依赖第二次 API 请求 |
| 恢复 | 刷新后恢复记录；到期未处理的项目再次出现，不伪装成已完成 |

新行事历与旧的每隔若干分钟休息提醒分开。日程提醒按绝对时间，不因切换宠物或暂停陪伴动画而移动截止时间。

## API 与可靠性

继续复用 [八家模型适配](companion-api-providers.md)。请求包含当前当地日期、星期、时区和当前角色说明；回复合同为 `chat / clarify / event`，`event` 只表示候选卡。HTML 使用通用 JSON 提示与严格应用校验，不将任意模型文字当成已保存结果，也不假设八家原生结构化输出参数相同。

AI 负责理解与措辞，程序负责有效日期、未来提醒、重复规则、事务保存和触发。JSON 格式也可能不完整；[DeepSeek 官方说明](https://api-docs.deepseek.com/guides/json_mode/) 提及 JSON 输出和空回包边界，因此解析失败必须回到聊天纠正，不能悄悄改用猜测时间。

Key 沿用现有会话内存，不放入行事历、URL、日志或图片。事件只保存在本机 Demo 专用存储；不发送整本行事历，不读取用户桌面或真实存档。实际浏览器调用仍受服务的 CORS、权限及额度影响。回归使用模拟接口；没有真实密钥，不声称八家线上语义理解已验收。

## HTML 与桌面程序的边界

HTML 只在页面可见时演示到点提醒。返回、刷新或重新打开会检查错过的提醒；关闭页面及电脑关机时不提醒、不唤醒。后台网页定时器会被限流，见 [MDN 页面可见性说明](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)。这不能替代 Windows 后台调度。

拍板后再接入原生：

- 沿用头顶聊天及云朵面板，增加持久化日程服务。
- 保存 UTC 时刻、原时区和当地重复规则；更换系统时区时确认解释，不悄悄移动用户约定的时间。
- 应用常驻时用本机调度，到点不访问 API；启动、休眠恢复和系统时钟改变后重新检查，按事件与发生次序去重。
- 隐藏或躲藏时由原生提醒入口露出；不抢走正在输入的焦点，完成／延后结果持久化。
- 电脑关闭或应用完全退出时不承诺提醒；系统通知、自启动、多窗口归属、免打扰和跨时区规则在原生阶段单独验证。

本阶段没有把这些原生行为当作已完成。v1.0 标签和重要版本记录保留；本轮普通更新为 v1.1。
