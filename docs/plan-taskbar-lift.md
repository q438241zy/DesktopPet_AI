# 从任务栏提起与主动上移

2026-10-01 按用户确认的规则接入：**普通松手停在当前位置，按住 Shift 松手才下落。** Preview 16 补上碰到任务栏后自动散步，不受当天打卡限制。打卡不再强制睡眠，只有主动休息才睡觉；自动散步开关和减少动态效果仍受尊重。

| 手势 | 结果 |
|---|---|
| 普通拖放，不论快慢、起点与停留时长 | 停在选定位置并保存 |
| 松手时按住 Shift，离地超过 24px | 自然落到当前屏幕工作区底边；开启自动散步时缓冲后走动并保存 |
| 距底部 24px 内松手 | 吸附到底部，缓冲后按自动散步设置走动，不重复下落 |
| 下落途中重新抓住 | 立即中断重力，跟随鼠标；普通松手停住 |
| 取消拖动、失去捕获或焦点 | 安全放置，不视为 Shift 下落 |
| 开启减少动态效果后 Shift 松手 | 直接完成落地，清除提起状态并保存 |

原生 `PetUp` 在松手时读取 Shift，再调用 `ReleaseLift(bool dropOnRelease = false)`。鼠标按住期间保持提起姿势和跟手位置；只有明确请求下落才进入 `DropToFloor()`。晃动后普通放置仍保留原地头晕恢复；Shift 下落清除摇晃状态，避免恢复动作与重力互相覆盖。散步及边缘躲藏保留先回到地面的流程。

独立 [交互 Demo](../Release/win-x64/Demo/TaskbarLift/index.html) 可从桌面 `DeepSeek-動作Demo.lnk` 的 MotionStudy 页面进入，或直接打开 `Release/win-x64/Demo/TaskbarLift/index.html`。三种示范为 Shift 松手下落、普通松手停住、半空接住；真实拖动时可实时查看 Shift 提示。支持 Q版/3D真人 × 原装/泳装/婚纱，引用当前常态 Demo 的 95 张现有无损帧，包含每套外观 12 个行走姿势，不添加新的图片副本。常态 `DeepSeek-demo.html` 与全角色动作清单同步，素材继续放在 D 盘。

验证覆盖全部 16 个角色条目、48 套外观的普通放置、两种起点的 Shift 下落、途中重抓、落地散步、关闭自动散步后的清醒待机、位置保存及减少动态效果；另回归摇晃、散步和既有互动。浏览器测试执行实际输入处理器，检查松手当下的修饰键、意外捕获丢失及取消。

本次仅修改交互，不替换画稿。Q版婚纱现有提起末帧仍偏坐姿，后续美术修改应补更明确的悬空与缓冲姿势，并保持当前服装一致；不能把交互修正视为新姿势图已完成。浏览器任务栏是模拟区域，多屏幕与实际任务栏手感仍可继续在 Windows 上试用。
