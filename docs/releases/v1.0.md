# v1.0 · 重要版本

2026-10-09，依使用者指示，将云朵伙伴当前源码与 HTML Demo 定为 **v1.0 重要版本**。

## 版本内容

- 八位伙伴：DeepSeek、GPT、Claude、Gemini、Grok、Qwen、GLM、Kimi。
- Q版与3D真人；原装、短袖短裤运动服、泳装、婚纱，共 64 套外观。
- 已有原生功能包括桌面散步与提起、照顾与玩耍、角色聊天、伙伴档案、月/周历打卡、收藏及工作模式。
- 最新 HTML Demo 支持随心/站立/坐下三种待机选择，以及 2–8 位伙伴、文字和相框的合照 PNG。
- README 增加控制面板、两种风格合照和日历的五张展示图。

## 交付范围

本次更新版本来源、HTML Demo 数据和公开说明，**没有新增原生功能或制作正式安装包**。已部署桌面程序仍为 v0.5；站坐选择与 2–8 人合照仍在 HTML Demo 中。现有图稿可切换姿态，但未新增连续起身、落座动画。

八家模型接口通过协议模拟验证，未以真实付费账号逐家测试。会员仍为本机账号，测试期适用功能开放。

## 验证与展示隐私

- [v0.6 功能验证](../verification-v06-demo.md) 覆盖 64 套站坐、56 种人数/服装合照布局、混搭导出及月/周历；本次没有修改这些功能实现。
