# 未打卡与落地散步 · Preview 16

2026-10-01 修正宠物接触任务栏后一直睡觉的问题。原因是旧逻辑把「今天没打卡」用作强制睡眠，并在 `StartWalk` 中禁止未打卡角色散步。Preview 15 的放置检查提前打卡，未覆盖此路径。

新逻辑不再将打卡作为睡眠或行走条件。开启「落地与闲时散步」时，启动在任务栏或落地缓冲结束后自动走动；普通放在半空仍保持位置。主动选择休息会保持睡眠，关闭自动散步或开启减少动态效果会保持清醒待机。打卡、收藏和服装保存逻辑不变，不自动补打卡。

`--verify-walk` 新增未打卡启动检查与独立的 `FloorWalkVerification`：逐套验证半空放置、Shift 落地、自动行走实际位移、普通地面放置、重抓取消、关闭自动散步、手动行走、减少动态、主动休息和之后的闲时散步。构建版本和发布版均通过 48 套外观的 576 项未打卡检查及 2888 项行走检查，含真实未打卡启动。发布版另通过 727 项放置与头顶聊天、792 项摇晃与恢复及 403 项互动检查。

常态 Demo 在接触地面后缓冲再行走，重抓会清除尚未执行的行走请求，减少动态时保持静止。独立 TaskbarLift Demo 复用六套外观现有的 12 个行走姿势，按实际位移推进脚步并在边缘短暂停步转向；95 张图片均引用原有无损文件。

常态 Demo 已由 Preview 16 发布版重新导出：六套 DeepSeek 外观、153 段动作、3524 张无损帧和 1248 行全角色动作清单，清单中的 48 套行走均标明未打卡也可落地散步。`verify-demo.cjs` 验证实际网页计时、落地缓冲与自动行走通过；`verify-taskbar-lift-demo.cjs` 的 334 项检查通过。
