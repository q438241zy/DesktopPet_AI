# 透明圆盘菜单

2026-09-28，按用户要求去掉圆盘菜单和子菜单的云朵底板、边框及底板阴影。图标使用圆角曲线和圆形端点，颜色改为柔和的玫瑰灰；细浅色描边只沿图标线条分布，帮助它在深色壁纸上保持可辨识。悬停轻微放大，按下轻微缩小，仍保留简短提示和键盘焦点环。其它设置页沿用现有图标。

![实际 WPF 渲染在浅色、深色背景上的对照](images/menu-transparent.png)

圆盘按钮的 44×44 点击范围采用 `#01FFFFFF`，即仅 1/255 的 alpha，视觉上无底板。这样保留完整鼠标目标；Windows 分层窗口会让 alpha 为零的像素穿透鼠标，参见 [Microsoft 的分层窗口说明](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features#layered-windows)。检查实际 PNG 的按钮空白区域得到 `(255,255,255,1)`，菜单外为 alpha 0。图中的背景对照由 WPF 截图合成，不是概念图。
