# Preview 26：行走中点击、提起与便携包

2026-10-06。修复用户报告的“走路时无法用鼠标提起或点击互动，人物继续走路”。全部角色和服装继续使用已批准画稿，本轮没有重新生成或改变体型。

角色以独立的透明输入层接收鼠标，覆盖当前姿势。动画切换到隐藏原 Image 的三维绘制层时，仍保留同一输入对象与鼠标捕获。左键按下立即清除散步、探索及待执行回调；短按继续轮换摸头、揉脸、挠痒，超过拖动阈值进入提起。读取屏幕鼠标坐标，避免移动中的窗口影响拖动起点；无左键按住的 MouseMove 不触发提起。右键仍只开关菜单。

普通松手停在放置位置；Shift 松手下落。靠近任务栏仍按既有规则落地、缓冲后散步，取消或捕获丢失不会误作 Shift。
