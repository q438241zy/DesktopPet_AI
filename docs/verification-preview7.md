# Windows 验证记录

日期：2026-09-28。版本：1.2.0-preview.7。Windows x64、.NET SDK 10.0.302。

## 本轮内容

八位伙伴的 3D／真人版，各自原装、泳装、婚纱，共 48 套外观新增十六姿势图集，共 768 个关键姿势。倾听、说话、发呆、起跳、腾空、落地、坐下、蜷紧、侧躺、拿积木、放积木、松手、提起、悬挂、球碰到身体与球落空分别选帧。进食保留上一版画稿；新动作不借用 Q 版或其他服装。

聊天窗口可以输入、发送、停止。API 地址为空时只运行本机预设多轮对话；填写地址和模型后使用兼容 Chat Completions 的服务。地址与模型保存在本地，金钥只保留在当前窗口内。测试没有连接真实模型服务，也没有使用用户的 API 金钥。

## 自动检查

- 核心行为检查覆盖聊天上下文、请求格式、最近 24 条上下文、取消、错误响应、跳跃轨迹与身体扫掠碰撞。新增回归确认 3D／真人的挠痒不会因新增跳跃图而误用跳跃姿势。
- Release 构建零警告、零错误；24 个角色条目、1056 个图像定义均实际解码。
- WPF 集成检查覆盖 72 套外观、双向步态、服饰保持、动作选帧、脚底位置、尺寸、角色导入、分类同步和存档重载。
- 专项互动检查覆盖真人舞蹈、画风权限、圆盘边界和键盘操作、透明窗口的实际绘制、躲藏完整时序及取消复位。
- 细节检查逐套核对 48 套外观的摸头、挠痒和进食素材；检查休息呼吸、点击唤醒、重复早餐、二十种物品和十种球类。
- 接触检查逐套播放零食、早餐、球碰到身体后向外弹开、远处投球落空；命中不会把球固定到手肘或手掌。另模拟界面停顿，确认投球按实际经过时间结束，不会因物理步长上限而一直等待。
- 姿势检查逐套核对发呆闭嘴、聊天两种姿态、腾空与落地、坐姿蜷起、侧躺身高及呼吸、拿放积木、工作列提起和释放落地；减少动态关闭腾空位移。文字框和发送按钮实际完成三轮本机对话，同一伙伴换画风保留对话，换伙伴会取消旧回复。

## 视觉核对

48 张最终原始图集均检查了人物、服装、姿势排列和头脚完整性。安装审计确认透明通道、十六个分离且非重复的姿势、裁帧边界和 SHA-256；最终素材与清单一致。安装脚本只读取像素与复制原图，不改写或重新编码图片。提示词、修订来源和裁帧记录见 `artwork/interaction-poses/`。

程序使用真实 WPF 渲染导出动作画面，并在淡灰背景上合成，避免看图软件忽略透明通道而显示不可见的边缘 RGB。示例：[侧躺休息](images/pose-rest.png)、[搭积木](images/pose-blocks.png)、[腾空](images/pose-jump.png)、[提起](images/pose-lift.png)、[文字聊天](images/local-chat.png)、[球命中后弹开](images/ball-hit.png)、[球落空](images/ball-miss.png)。

本轮通过 WPF 控件事件、真实动画时序、程序自身渲染与进程启动验证，没有通过系统鼠标注入复核。此前桌面控制工具抓图返回黑图，激活报 `failed to activate captured window`，因此这些检查不能称为系统点击验证。

## 复现

`tools/check.ps1` 运行全部核心、素材、WPF 和互动检查，使用独立的 `--data-dir`。测试不会修改日常角色选择、打卡和收藏。

专项运行同样必须提供独立数据目录：

```text
DesktopPet.exe --verify-interactions --data-dir <独立目录>
DesktopPet.exe --verify-details --data-dir <独立目录>
DesktopPet.exe --verify-contacts --data-dir <独立目录>
DesktopPet.exe --verify-poses --data-dir <独立目录>
```

`--contact-pilot` 可缩小到 Qwen 3D 泳装，`--pose-pilot` 可缩小到 DeepSeek 3D 原装。修订单套素材时可使用 `--appearance deepseek-adult-wedding` 指定外观；完整检查不带这些选项。日志和额外截图保留在本地 `artifacts/`。

## 行为与显示范围

- 本轮新增的是离散关键姿势，配合程序位移、呼吸及球的物理运动。摸头、揉脸、挠痒和真人舞蹈仍使用立绘骨骼；没有实时三维模型或大幅转身的遮挡纹理。
- Q 版保留自己的图集和同服装回退规则；3D／真人新画稿不会作为 Q 版回退素材。
- 玩球只有一个入口，旧推球动作键兼容到玩球。十种运动玩具和二十种散步物品继续使用原抽签与永久收藏。
- 从工作列提起后正常松手会落回当前工作区底部；减少动态时直接放置。快速左右甩动仍保留原有晕眩反应。
- 躲猫猫沿原显示器工作区边缘裁切。尚未在真实不同 DPI 的多显示器、Windows ARM、macOS 或 Linux 上验证。
- API 分支通过模拟 HTTP 传输验证；真实服务的可用性、认证方式及模型效果取决于用户配置。

绿色发布版必须保留 EXE 旁的 `Assets` 与 `Studio` 目录。桌面“云朵伙伴”快捷方式指向 `Character/Release/win-x64/DesktopPet.exe`；用户数据继续位于 `%LOCALAPPDATA%/DesktopPetAI/`。
