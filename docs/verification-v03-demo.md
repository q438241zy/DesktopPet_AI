# v0.3 Demo 验证

2026-10-07；审阅入口保持 `Release/win-x64/Demo/CompanionV01/index.html`。

本轮改动：

- 整月日历直接点击当天打卡，今天使用玫瑰色，已签日期保留数字；补签卡默认 0 张。补签需确认，消耗 1 张，取消不扣卡，不能补签今天、未来或重复日期；补签不补发好感，也不虚构陪伴时间。支持翻月、返回今天、跨日和跨月更新。

- 按用户澄清恢复原控制面板角色卡：原图、名称、服装切换。主页不再显示新互动舞台；既有聊天、躲藏和合照留在独立预览页，可从档案「和她聊聊」或左下角版本测试工具进入。角色图使用原始素材与等比绘制，窄屏额外限制横向尺寸以避免裁掉头发。
