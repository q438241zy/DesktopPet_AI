## 交付范围

- 打卡区月历/周历切换，共用记录；直接点今天打卡并立即标记，跨日刷新、翻页、回到今天。补签默认0张，有卡确认消耗1张补过去日期，不增加关系值或陪伴时间。
- 我的伙伴保留八角色原图卡和原控制面板的角色/服装卡；右键或 Shift+F10 进入「我们的默契 / 风格预览 / 说明」。八角色的描述、四项喜好、口吻与API提示来自同一份定义。
- 关系 −100..100 和实际可见陪伴时间按角色家庭独立保存，Q版/3D真人共用。正向每日20分上限、互动冷却，六次连续逗弄有温和边界和扣分；不把旧打卡天数虚构成历史陪伴时间。测试期间风格和服装继续全部开放。
- 聊天在角色头顶，离线预设多轮与API回复均至少思考一秒；切换角色保留各自的会话，取消旧请求；退出账号清空会话和密钥。八服务的原生协议见 [接口核对](companion-api-providers.md)。
- 闲置60秒或手动躲藏时走向边缘，探头后一直等待左键找到；右键仅开关菜单。设置、合照窗口和正在聊天时不自动躲藏，收起聊天后的未发草稿不阻止闲置计时。
- 工作模式默认关闭，开启后设置1–180分钟，默认10分钟。八角色各六条预设提醒；API可用时尝试生成，失败明确保留预设。独立笑脸提醒不打断当前互动；关闭、隐藏宠物、换角色或接口取消待返回请求。隐藏期间暂停倒计时，不补发积压提醒。
- 合照选择另外七位同风格伙伴之一，保留双方所选服装，文字和三款相框，输出1200×1400 PNG。原图等比绘制，两人使用共同的比例限制，完整容纳宽发、裙摆和尾巴；保存对话框默认桌面，取消不显示成功。
- 会员中心为登录/注册分页，沿用本机盐化密码摘要与实际账号等级。日常为日历和球/食物/故事收藏，保留已有其他收藏与收藏球的玩耍入口；移除该页礼物抽取入口。角色工房、生成器附件与专用导入器移除，已有用户角色数据保留。
- 设定去掉底部说明/额外入口；侧栏只保留品牌、红绿呼吸状态灯及统一版本。
