# v1.10：已批准控制面板接入原生

用户批准 v1.9 HTML 设计，并要求更新日常程序、从原桌面入口启动，确认 Q版与3D真人的角色卡都会随机动作。本轮不制作正式安装包，Gitee 保持暂停，v1.0 重要标签保留。

## 接入内容

- 我的伙伴八张卡分别使用控制面板自己的真实计时器，随机站立、坐下、托腮、伸展和笑脸，抽取 1–2 秒间隔。桌面宠物的固定站坐、当前互动、聊天草稿或隐藏状态不会锁住角色卡；当前伙伴的大卡仍尊重用户保存的姿态选择。
- 卡片提供独立暂停预览。离开伙伴页、隐藏或最小化控制面板、模态窗口和减少动态效果暂停预览，恢复时重新计时。预览不增加好感度、互动次数或重置宠物闲置时间。
- 当前页为每张卡保留无损原分辨率帧与布局，不再每次重绘都争用全局图集缓存。只保留当前画风、服装和尺寸；切页或关窗释放。首次解析图集仍需加载时间，没有通过缩图换取速度。
- 行事历合并月／周打卡，月份显示包含相邻月份的 42 格，周历 7 格；点今天签到、过去日期补签确认、未来日期看日程。日程输入可展开，切换日期或后台收藏刷新保留未发送文字和编辑草稿；离开行事历仍取消未确认请求。
- 陪伴日常为「动作 / 图鉴收集」：15 项玩耍、12 项互动；图鉴包括 10 种球、6 种食物、4 种其他小物和 10 篇故事。保留已有收藏及阅读次数。
- 设定内分「陪伴与提醒 / AI 接口 / 账号与会员」，继续使用已有本地账号服务及八家模型适配，会员测试期开放。
- 已批准 Q版云朵宠物几何接入控制面板、窗口、托盘、EXE 与快捷方式图标。图标含 16–256 像素九个尺寸，生成脚本可复现。

本轮沿用已批准的角色与服装图稿，没有新增角色图、降低图片分辨率或变更桌面动作编排。

八家 API 使用本机模拟响应，真实付费调用为 0。没有重跑与本轮未改行为无关的全套物理鼠标测试。
