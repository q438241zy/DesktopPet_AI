# v1.2 · 原生宠物行事历

2026-10-09，用户对 v1.1 行事历 HTML 方案回复「同意」，本轮接入 Windows 桌面程序。重要版本 `v1.0` 标签保留；普通版本推进至 `1.2`。

## 本次实现

- 原有头顶聊天复用八家接口及角色性格，普通聊天、时间追问、日程候选使用同一合同。成功与错误回复都先完成至少一秒思考；没有 API 时明确引导设定，不假造自然语言记事。
- 可编辑确认卡显示事情、绝对日期时间、提前分钟、重复方式、负责伙伴和时区。确认才写入；错误时间、取消、关闭聊天、换角色和过期请求不会创建日程。卡片按实际布局高度重新定位，120/200/280 角色尺寸下不覆盖脸部。
- 左侧「宠物行事历」提供周/月、当天/全部、待提醒/已完成、修改、确认删除与无副作用预览。八位伙伴共用日程，各事件保留负责伙伴。
- 独立本机时钟按绝对时间检查，不依赖走路、工作模式、动画、宠物可见性或 API。提醒使用所属角色当前画风/服装的原有笑脸；完成及延后十分钟持久化，多件事逐件处理。
- 独立 `agenda.json` 以临时文件刷新磁盘后替换，保留上一份 `.bak`。写入失败不改变内存状态；读取损坏时保留文件并阻止覆盖，不重置用户日程。旧宠物、账号和聊天设置文件保持各自原用途。
- 启动、休眠恢复和系统时间变化均检查未处理事件。重复支持单次、每天、工作日、每周，处理后跳过错过次数，保持原钟点；不连续刷出积压提醒。更改系统时区后，重复日程需修改确认；夏令时缺失或歧义时间不静默猜测。
