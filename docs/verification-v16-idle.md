# v1.6 · 每 1–2 秒随机待机 Demo

2026-10-10。用户反馈宠物一直坐着，希望没有互动时缩短到 1–2 秒出现不同动作。本轮遵守既定的先 HTML Demo、确认后接入规则；没有覆盖桌面原生程序。

## 原因与行为

原生 v1.4 使用 30 秒的站坐时钟，只有两种状态；打开聊天、进行互动等会暂停切换。本次只读取了日常存档的相关开关，未发现固定坐姿或减少动态开启。运行程序仍来自 `Release/win-x64/DesktopPet.exe`，与已安装 v1.4 一致。

Demo 当前角色卡的“自动 · 1–2秒”随机轮换站立、坐下、托腮、伸懒腰和笑脸。每段从 1000–2000 毫秒抽取，同一姿态不会连续重复，轮完其余四种再重新抽取；固定站立/坐下仍保留并记住选择。八位角色的 Q版/3D真人、原装/运动服/泳装/婚纱共 64 套都采用自己的素材。

自动姿态时钟与用户活动时钟独立，不触发互动奖励，也不推迟一分钟躲藏。聊天草稿、回复、摸头、菜单、待确认行事历、暂停、减少动态、隐藏页面和模态框优先。恢复时重新等待 1–2 秒；长时间离开不补播一串动作。空输入框本身不阻止预览待机。

使用原有全身图片，伸展完整八帧按该段间隔播放，托腮保留原有帧顺序。显示空间按全部待机帧预留，脚底共用基线，无局部拉伸或切姿势时透明闪烁；新图未就绪时保留上一帧。手机舞台增加顶部空间，举手不被输入框遮住。站坐之间仍为姿态切换，本轮没有生成连续起身/落座图片；部分旧 Q版站姿仍是先前的侧面素材。

复核时发现 Q版泳装/婚纱的笑脸原先回退到单张普通坐姿，已复用各自五项互动中的 happy 帧；部分托腮图集裁切混入邻格发丝，补齐原有分格归属遮罩。没有改写原始图片像素，也没有跨服装借图。v1.5 的 Claude 正面候选及纯聊天继续待审。

## 交付范围

入口 `Release/win-x64/Demo/CompanionV01/index.html?review=idle-v16`；源码与 HTML 版本为 **v1.6**，日常程序仍为 **v1.4**。桌面同一 Demo 入口保留，所有项目文件仍在 D 盘。源码按持续授权推送 GitHub，不上传 Gitee、不制作正式安装包。用户确认后再接入原生。

增量生成既有素材的待机几何：

```powershell
python tools/build-companion-demo.py --idle-only --target docs/demo/companion-v01
```

`idle-art.js` 仅包含现有图片路径、分帧和归属数据。生成器不复制或重新编码图片；普通完整导出也会生成该文件。
