# v1.7 · 自动礼物、阅读与小范围追蝶 Demo

本轮按用户持续规则先更新 HTML，尚未获准替换日常程序。当前 HTML 为 v1.7，日常 Windows 程序仍为 v1.4。先前 v1.5 纯聊天/Claude 站姿和 v1.6 快速待机也仍在同一个待审入口中。

## 本轮行为

- 拆礼物：一次选择后，使用者一侧的手把礼物递过去，宠物接过、拆开、展示随机物品。取消前尚未打开时不发奖；打开后只记一次收藏，沿用 20 种球类/日常物品，抽签一袋内不重复。没有问答、递出和拆开确认按钮。
- 一起阅读：随机选择故事，避免紧接着重复上一篇；自动显示每句文字并翻页，最后一句读完才收藏。用户明确选择无语音，不调用语音服务。保留三篇旧故事及其 ID，增加七篇原创短故事，共十篇，每篇 7–8 句。故事收藏允许点选重读。
- 捉蝴蝶：开始即沿限定范围追逐，缓入缓出转向，步态推进按移动距离计算，画面朝向跟随实际移动方向；最后停在站姿。不会用坐姿图片横向滑动假装走路。
- 玩耍包含原玩耍和动作；互动包含原照顾和休息。「早餐」改为「吃饭」，「零食」改为「吃零食」；躲藏只保留一个入口。聊天仍在第一层。
- 圆盘保留透明底，较多动作分组分页；侧栏和选中菜单图标显示填充形态，非选中仍为线形。
- 当前 Demo 移除合照入口、弹窗、生成和保存代码，不再加载或导出合照图像副本。历史用户照片与原生安装未修改。

## 素材与范围

`play-art.js` 由 `tools/build-companion-demo.py --play-only` 生成，引用八角色、两种画风、四套服装的现有全身帧、脚底坐标及手/书/盒子锚点，不生新图，不改变原始 PNG，不拼接关节。人物使用固定参考尺度。礼物揭晓后将原图盒子前壁重新遮盖于物品前，避免奖品盖住手。

新增故事只写入 Demo 的 `story-library.js`，原生 `StoryLibrary.cs` 留待批准后接入。原生菜单也没有提前替换。不同画风旧素材的细节连贯性仍以本轮画面审阅为准，自动检查不能替代用户对美术的判断。

## 复现

```powershell
python tools/build-companion-demo.py --play-only
node tools/deploy-companion-preview.cjs
node tools/verify-play-preview.cjs
node tools/verify-play-timing.cjs
node tools/verify-simple-chat.cjs
node tools/verify-idle-variety.cjs
```

从完整源码重建可使用 `tools/install-companion-demo.ps1`。增量部署只更换 HTML、脚本、样式和派生几何；原生 exe、素材及日常用户存档均不作为写入目标。
