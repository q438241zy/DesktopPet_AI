# Windows 验证记录

日期：2026-09-27。版本：1.1.0-preview.1。Windows x64、.NET SDK 10.0.302。

## 已执行

`tools/check.ps1` 包含以下检查：

- 12 项核心行为检查：同日打卡去重、中断不扣亲密度、闰年与纪念日、服装动作回退、动画时间边界、行走边界与原画朝向、按动作周期计算移动速度、快速投球扫掠碰撞、甩动换向阈值、原子存档、损坏存档备份、导入路径、分类及数据校验。
- Release 构建，零警告、零错误。
- 10 个角色条目（八位 Q 版与两个风格 Demo）、186 个图像定义全部实际解码并检查图集可均分。
- 88 项 WPF 集成检查：三类十形象切换、小埋目录移除与旧选择回退、婚纱选择保持、重复页面导航、打卡幂等、取消告别及恢复已休息角色、八角色两种服装双向行走的朝向和脚底位置、边缘转身、静态 Demo 禁止假行走、生成器成果导入、分类保存与存档重读。

实际窗口检查了云朵首页、分类导航、DeepSeek 风格对照和新云朵滑块。滑块通过键盘调节后，尺寸数值与存档同步更新。云朵开关的整行透明区域已补充点击命中，避免只点文字才有效。

自包含发布包将 `Assets` 与 `Studio` 保留为程序旁的真实目录。ZIP 不包含调试符号或测试存档，完整解压后运行。

## 验证范围

Q 版素材沿用 DS Go 现有画稿；未完成的新动作使用明确回退。两张成年风格 Demo 仅为透明静态立绘，不是实时 3D 模型，也没有扩充完整逐帧动作。当前机器上验证了透明窗口与高 DPI 显示，未在不同 DPI 的多显示器、Windows ARM、macOS 或 Linux 上验证。球碰撞使用角色中心近似圆，未逐像素采样角色透明度。

`docs/images/pet-home.png`、`docs/images/deepseek-styles.png` 与 `docs/images/cloud-settings.png` 由实际 WPF 内容渲染导出；不包含桌面或其他应用内容。测试目录另外保存 DeepSeek 原装、婚纱向左与向右行走时的真实宠物画面。测试数据、测试导入角色和日志仅在忽略的 `artifacts/` 下，不随发布包交付。
