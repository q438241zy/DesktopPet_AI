# Windows 验证记录

日期：2026-09-27。版本：1.2.0-preview.2。Windows x64、.NET SDK 10.0.302。

## 已执行

`tools/check.ps1` 包含以下检查：

- 15 项核心行为检查：同日打卡去重、中断不扣亲密度、闰年与纪念日、同服装动作与姿势回退、静态角色服饰保持、仅当前服装授予行走能力、旧动作包兼容、动画时间边界、行走方向与速度、球碰撞、甩动阈值、原子存档及导入校验。
- Release 构建，零警告、零错误。
- 24 个角色条目（三种画风各八位）、288 个图像定义全部实际解码并检查图集可均分。
- 10030 项 WPF 集成断言：全部 72 套外观的 25 种动作在多个时间点只取当前形象服饰；实际窗口显示与完成后的保留；每套外观双向行走、换帧、朝向及脚底位置；成年形象行走前后尺寸一致；行走途中换装与切换画风；分类按钮同步应用同一角色服饰；跨角色记忆及存档重载。另保留原有打卡、休息、导入、导航和边缘转身检查。

`python tools/verify-style-art.py` 另检查全部 48 张 3D / 真人版 PNG：RGBA 透明通道、可见像素、尺寸、完整轮廓边界及 SHA-256 去重。48 张全部通过，无缺失、无重复、无触边图片。检查脚本只分析图片，不修改像素。

`python tools/verify-motion-art.py` 检查本轮新增 56 张行走 PNG：1536×1024、RGBA、六个非空且不重复的完整透明单元格、无跨单元格触边、整图 SHA-256 去重。56 张全部通过。原生成文件未经离线像素加工，边界问题通过 image_gen 重新编辑修正。

实际窗口检查了云朵首页、分类导航、DeepSeek 风格对照和新云朵滑块。滑块通过键盘调节后，尺寸数值与存档同步更新。云朵开关的整行透明区域已补充点击命中，避免只点文字才有效。

上一轮已用日常实例检查八位 3D 角色目录、风格对照和真人版 DeepSeek 婚纱。本轮完整 WPF 集成测试在独立数据目录运行并正常退出，不改动日常打卡与收藏。更新前日常存档备份在本地 `artifacts/state-before-continuity-preview.json`。窗口控制工具在日常实例上返回 `failed to activate captured window`，因此该实例的人工式操作复核需在桌面恢复可操作后继续。

自包含发布包将 `Assets` 与 `Studio` 保留为程序旁的真实目录。ZIP 不包含调试符号或测试存档，完整解压后运行。

发布后的 EXE 成功解码 24 个角色、288 个图像定义。ZIP 的 24 份角色清单、288 个素材引用、56 张新行走图的 SHA-256，以及 344 个归档条目的 CRC 均通过检查。验证日志保存在本地 `artifacts/`。

## 验证范围

Q 版原装与婚纱素材沿用 DS Go 现有画稿，泳装新增行走。3D / 真人版使用 48 张立绘及 48 张行走图集，不是实时 3D 模型。未绘制的其他互动使用当前服饰姿势图；AI 生成步态仍可能有局部细节变化，不等同于骨骼动画。当前机器上验证了 WPF 透明窗口与高 DPI 显示，未在不同 DPI 的多显示器、Windows ARM、macOS 或 Linux 上验证。球碰撞使用角色中心近似圆，未逐像素采样角色透明度。

`docs/images/` 的截图均由实际 WPF 内容渲染导出；不包含桌面或其他应用内容。测试目录另外保存八角色三种服饰共 24 张风格对照页、成年风格完整角色列表，以及 DeepSeek 三种画风、三套服装的双向行走画面。测试数据、测试导入角色和日志仅在忽略的 `artifacts/` 下，不随发布包交付。
