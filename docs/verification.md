# Windows 验证记录

日期：2026-09-27。版本：1.2.0-preview.3。Windows x64、.NET SDK 10.0.302。

## 当前版本

- 18 项核心行为检查通过。新增左右边缘躲藏的完整时序、负坐标显示器、不同尺寸、指定方向、舞蹈的起止姿势与节拍判定；保留全部服饰回退、步态、存档、碰撞和导入检查。
- Release 构建成功，零警告、零错误。
- 24 个角色条目、288 个图像定义全部实际解码。此版本没有更换角色美术。
- 原有 10030 项 WPF 集成断言通过：72 套外观的动作与服饰保持、双向步态、尺寸、脚底位置、换装、分类同步、导航、角色导入和存档重载。
- 发布版另通过 523 项 WPF 互动断言：所有 72 套外观的舞蹈与躲藏行走；Q版、3D版、真人版在左右两侧完整藏入、探头与返回；隐藏时存档恢复到屏幕内；探头时点击找到；取消与换装复位；减少动态效果；舞蹈结束；设置与菜单入口；120 / 280 尺寸在左右屏幕边缘的菜单边界。
- 设置页与动作面板均用实际 WPF 内容渲染导出。已查看主页、日常、偏好、工坊、四组动作面板和最小窗口宽度的布局。

检查使用独立的 `--data-dir`，不会修改日常角色选择、打卡和收藏。日志与额外截图在本地 `artifacts/`；`tools/check.ps1` 运行完整回归，`--verify-interactions --data-dir <独立目录>` 可单独运行新互动检查。

桌面控制工具能够找到原生窗口，但屏幕抓取返回黑图，重试激活仍报 `failed to activate captured window`。因此本轮没有完成通过系统鼠标注入的人工式点击复核；WPF 控件事件、动画时序、程序自身的渲染和进程启动分别验证，不能将它们称为系统点击验证。

## 行为与显示范围

- 躲猫猫默认走向最近的工作区边缘；也可指定左侧或右侧。沿当前服装的行走动画到达后藏起，再探出和返回；退出躲藏、切换外观、停止互动或关闭时不留下屏幕外存档。裁切采用出发显示器的工作区。
- 舞蹈是一段 16 拍、120 BPM 的程序化轻舞，以当前外观做摆动、位移和小跳，并提供视觉节拍及点击／空格跟拍。当前内置包不含专门绘制的关节舞蹈图集，也不播放背景音乐；角色包可提供同服装的 `dance` 动画。
- 全部形象仍使用二维图集；3D版和真人版不是实时 3D 模型。没有专用画稿的其他动作保持当前服饰姿势，不借用 Q版或原装。
- 负坐标与不同尺寸通过独立行为检查。尚未在不同 DPI 的真实多显示器、Windows ARM、macOS 或 Linux 上验证。球碰撞仍使用角色中心的近似圆。
