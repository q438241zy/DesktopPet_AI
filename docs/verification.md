## 行为与显示范围

- 圆盘只显示线形图标；悬停显示短名称。右键／Esc 收起，Shift+F10 打开，Tab／方向键切换，Enter 选择，Backspace 返回。靠边展开圆弧，空间足够时围绕角色完整成环。
- 舞蹈只对八位内置真人版开放，使用二维骨骼和网格蒙皮，程序控制肩肘、躯干、髋膝与脚踝。16 拍、120 BPM，有交替抬脚和裙摆随动。原装、泳装、婚纱使用当前纹理；取消、换装或结束后恢复普通立绘。点击／空格跟拍只改变节拍点的颜色，没有计分文案或背景音乐。
- 真人舞蹈基于现有正面立绘，适合小幅度轻舞。没有完整三维模型，也没有被遮挡肢体的独立纹理，不能完成背面转身或大幅交叉动作。婚纱下半身按连续裙摆处理，避免把长裙拉成两条腿。
- 躲猫猫仍走到最近或指定的工作区边缘，再藏起、探头、走回。退出躲藏、切换外观、停止互动或关闭时不留下屏幕外存档。裁切采用出发显示器的工作区。
- 全部形象仍使用二维素材；3D版是画风分类。没有专用画稿的其他动作保持当前服饰姿势，不借用 Q版或原装。
- 尚未在不同 DPI 的真实多显示器、Windows ARM、macOS 或 Linux 上验证。球碰撞仍使用角色中心的近似圆。
